# Editorial Preferences

## User-shared news links

When the user supplies a specific news link:

- Treat that link as the selected lead; do not replace it by searching for a different story.
- Skip broad topic discovery unless the user asks for alternatives.
- Preserve the supplied URL as the discovery source in the story record.
- Still verify material factual claims before publishing them as news.
- For allegations involving death, injury, crime, minors, sexual abuse, self-harm, public safety, or a named person, require official confirmation or independent reputable corroboration.
- If verification is unavailable, use only a clearly labeled `unverified viral claim` or `reports remain unconfirmed` framing when editorially useful.
- Never repeat an unsupported allegation as established fact merely because the link was user-supplied.

This preference changes story selection, not the accuracy standard.

## Local daily folders

- Store working assets under `Downloads/TezScroll News/YYYY-MM-DD/`.
- Create one clearly named story subfolder inside that daily folder.
- Keep the original source, generated illustration when applicable, notes, Canva export, and final publishing assets together in the story subfolder.
- Never mix assets from different dates or stories.

## Canva media framing

- Never crop a source image or video.
- Use the user-approved Canva reference placement: Width 1080 px, Height 1350 px, X = 0 px, Y = 317 px, Rotate = 0 degrees.
- Keep Ratio unlocked for this reference placement. Do not use Canva's Crop control; size the clip and move it down to preserve the white headline area.
- The video fills the full page width, begins below the headline area, and continues behind the date/logo overlays to the bottom page boundary.
- In Layers, keep the asset immediately above Background and below all text, branding, date, logo and highlight elements.

## Canva headline layout

- The visible headline must remain exactly three lines; shorten wording instead of allowing automatic wrapping to create a fourth line.
- Keep internal text alignment centred and centre the complete headline text box to the page.
- The approved reference headline box is Width 1089.2 px, Height 176.1 px, X = -4.6 px, Y = 229 px, Rotate = 0 degrees, with 41.2 pt text.
- Do not move other elements while correcting headline fit or alignment.
- Place the existing red highlight shape behind the selected main headline line. For this approved reference, the main line is line 1 and the shape is Width 894.9 px, Height 49.4 px, X = 92.5 px, Y = 229 px, color `#c42222`, rotation 0 degrees.
