# Editorial Preferences

## User-shared news links

When the user supplies a specific news link:

- Treat that link as the selected lead; do not replace it by searching for a different story.
- Skip broad topic discovery unless the user asks for alternatives.
- Preserve the supplied URL as the discovery source in the story record.
- Still verify material factual claims before publishing them as news.
- For allegations involving death, injury, crime, minors, sexual abuse, self-harm, public safety, or a named person, require official confirmation or independent reputable corroboration.
- If verification is unavailable, use only a clearly labeled `unverified viral claim` or `reports remain unconfirmed` framing when editorially useful.
- Never repeat an unsupported allegation as established fact merely because the link was user-supplied.

This preference changes story selection, not the accuracy standard.

## Local daily folders

- Store working assets under `Downloads/TezScroll News/YYYY-MM-DD/`.
- Create one clearly named story subfolder inside that daily folder.
- Keep the original source, generated illustration when applicable, notes, Canva export, and final publishing assets together in the story subfolder.
- Never mix assets from different dates or stories.
