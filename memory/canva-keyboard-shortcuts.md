# Canva Keyboard Shortcuts (Windows)

Official source: https://www.canva.com/en_in/help/canva-keyboard-shortcuts/

Last reviewed: 2026-08-03

## TezScroll priority shortcuts

- `Alt + 1`: Show Position → Layers. Use this before selecting a specific headline, shape, logo, date, image, or video layer.
- `Ctrl + Z`: Undo.
- `Ctrl + Y` or `Ctrl + Shift + Z`: Redo.
- `Ctrl + S`: Save.
- `Ctrl + F1`: Move focus to the editor toolbar.
- `Ctrl + F2`: Move focus to the canvas.
- `Ctrl + F3`: Move focus to the side panel.
- `Ctrl + /`: Toggle the side panel.
- `Tab` / `Shift + Tab`: Select the next or previous element.
- `Shift + F10`: Open More actions for the selected element.
- Arrow keys: Move a selected element in small increments.
- `Shift + Arrow`: Move a selected element in large increments.
- `Ctrl + Arrow`: Resize a selected element in small increments.
- `Shift + Ctrl + Arrow`: Resize a selected element in large increments.
- `Ctrl + ]` / `Ctrl + [`: Move an element forward or backward.
- `Alt + Ctrl + ]` / `Alt + Ctrl + [`: Move an element to the front or back.
- `Alt + Shift + L`: Lock an element.
- `Ctrl + D`: Duplicate a selected element.
- `Ctrl + B`: Bold text.
- `Ctrl + U`: Underline text.
- `Shift + Ctrl + C`: Centre-align text.
- `Alt + Ctrl + C` / `Alt + Ctrl + V`: Copy or paste text style.
- `Alt + D`: Toggle duration.
- `Space`: Play or pause video.
- `M`: Mute or unmute video.
- `Ctrl + +` / `Ctrl + -`: Zoom in or out.
- `Alt + Ctrl + 0`: Zoom to fit.

## TezScroll editing safeguards

1. For both image and video posts, select the intended container and press `Alt + 1` to open Layers.
2. Select the exact named layer from the Layers panel. Do not select the full canvas when only one element needs changing.
3. Never group or ungroup template elements during routine post creation.
4. For a mixed-colour three-line headline, replace each existing line separately. Do not replace the whole text box at once, because Canva may copy line 1's white formatting to lines 2–3.
5. Keep the headline at exactly three visible lines. Shorten wording if Canva wraps a line.
6. Keep line 1 white over the red bar and lines 2–3 black.
7. Do not move, resize, delete, or restack unrelated layers while editing text.
8. Keep image or video immediately above Background and below headline, red bar, date, logo, and other branding.
9. Never crop media; scale it to fit the frame.
10. Before export, verify the headline, red bar, date, logo, and media are all visible and correctly layered.

The official Canva Help Centre is authoritative if shortcuts change.
